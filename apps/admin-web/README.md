# @autodeck/admin-web

AutoDeck's web admin console (Next.js) for Owner/Admin and Studio Manager roles: staff and role management, pricing/service catalogue, package definitions, bookings oversight, refund/cancellation controls, minimal inventory management, audit-log viewer, and basic operational reporting. Never accessible to customer or Staff-role accounts; shares no UI code with customer-facing surfaces (separate trust boundary).

**Status**: repository scaffold only. No pages or business logic implemented yet.
