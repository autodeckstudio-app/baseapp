# @autodeck/customer-mobile

AutoDeck's native customer app for iOS and Android (React Native / Expo, EAS Build for genuinely native binaries — not a PWA wrapper). Covers garage, vehicle detail, booking, live visit tracking, mid-visit approvals, packages, in-app payment, history, and profile, per Google Sign-In.

**Status**: repository scaffold only. No screens, navigation, or business logic implemented yet. Framework-specific config (`app.json`/Expo config, EAS build profiles) will be added when this app is actually initialized in the implementation phase.
