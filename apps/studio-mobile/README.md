# @autodeck/studio-mobile

AutoDeck's native studio-staff app for iOS and Android (React Native / Expo, EAS Build). Each staff member authenticates with their own individual account (no shared/anonymous login); job title is display metadata only and never affects permissions. Covers schedule/board, job stage advancement, walk-in intake, approval-request initiation, package consumption, and minimal inventory recording, role-scoped per the Staff / Studio Manager / Owner-Admin permission model.

**Status**: repository scaffold only. No screens, navigation, or business logic implemented yet. Framework-specific config will be added when this app is actually initialized in the implementation phase.
