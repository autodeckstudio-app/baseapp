# @autodeck/customer-web

AutoDeck's browser-based customer experience (Next.js) for customers who prefer a laptop/desktop, including service booking. A standard web application — explicitly **not** a PWA/wrapper and does not reuse AutoModz's excluded PWA architecture. Talks to the same backend and is subject to the identical server-side business rules, auth, and data model as the native customer app.

**Status**: repository scaffold only. No pages or business logic implemented yet.
