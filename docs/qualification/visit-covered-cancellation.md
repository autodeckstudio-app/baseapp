# Covered-zero service cancellation, local and dormant

This Admin-only writer is not imported by a production route. It requires an
exact full-visit review, unstarted work, original covered-zero invoice and
consumed wash linkage. It refuses any physical request or extra money/work.
A remaining sibling uses the existing no-cancellation-fee rule. A final service
with an existing policy fee is held, not silently waived because it cost zero.

The transaction restores exactly one proven consumed wash, clears only that
booking/job's consumption marker and creates one private cancellation plus one
membership restore marker. Concurrent/retried calls cannot restore twice.
An expired plan stays expired. No money, gift or pickup benefit is restored.
Original issued zero invoice and historical usage row remain unchanged.

The billing reader verifies both original snapshots and the exact separate
restore marker after cancellation. Later legitimate membership usage can change
the membership's counter; that does not rewrite this service's history. The
sibling can receive its own real payment/invoice, with the cancelled covered
original still visible and no manufactured cash receipt.

Still held: general membership-discount cancellation, unissued covered work,
gifts, final policy fees, benefit transport and visible reporting/control wiring.
No tax/credit-note decision or UI change is made here. Current live baselines,
complete routed before/after visuals and owner approval remain required before
live use.
