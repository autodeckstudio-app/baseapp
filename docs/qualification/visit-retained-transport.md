# Original funded transport retention, local and dormant

No production callable imports this path. The existing live closed-booking
transport guard is not relaxed, and there is no release or provider activation.

The exact original-request review can now be included in the immutable service
cancellation plan. It requires the original transport-bearing obligation to be
fully funded, exact original price/quote legs and no benefit. The cancelled
service's return is original funding minus its existing service cancellation
fee and retained original transport. No cancellation fee applies while another
booked service proceeds. Issued invoices and original payments/receipts stay
unchanged. Retained transport is not moved, rebilled or charged to a sibling.

An immutable private retention fact keeps the original booking/request and
financial anchor. Cancellation does not decline, copy or move the physical
request. Request progress may only move forward; original completion stamps,
quote, prices and ownership stay exact. A proposed unused leg must be explicit
and cannot be a completed leg. Its original amount is added to the separate
Admin original-method return review, never reported as automatically refunded.
The original request is not silently marked DONE to mean an unused leg happened.

A separate dormant progress seam can finish the original retained physical drop
after the anchor's service/booking are cancelled. It rechecks every surviving
service's payment, performed work, invoice and the actual shared handover. It
never revives the cancelled service, creates another trip or returns the car
while sibling work remains unfinished. Actual guarded surviving-service work,
handover/delivery and retained drop are exercised together in emulator tests.

Still held: partially funded/unfunded original transport, benefit transport,
unknown old snapshots, explicit physical closure/display of proposed unused
legs, and applying the decision to visible live controls. The current tested
slice requires existing confirmed times for physical progress. Fee-due,
benefit/gift cancellation and report/control wiring remain separate work.
A current baseline and full routed before/after visual approval are still
required before any live change. Nothing here decides accountant tax/credit-note
treatment or changes an issued invoice.

A later removal of the final surviving service is held while a previously
retained journey is unfinished, rather than silently stranding or closing it.

batches (225 existing plus 14 new retained-transport cases); all 134 private-money
rules pass. Functions types/build pass. No UI/pixel acceptance is claimed.
