# Local customer Home working preview

Actual Home components with synthetic props. No account or integration writes. Every action reports its callback label instead of performing a booking, quote, payment, contact, or external navigation.

The ready-to-open ZIP supplied for review includes index.html and preview.js. Source build: `node scripts/visual/customer-home-scene/build.mjs`. The generator uses real application components, aliases react-native to react-native-web and stubs external account/data dependencies. Production bundles use the unmodified real integrations. Fixture imagery is labelled illustrative and is not a customer photo or a real listing.
