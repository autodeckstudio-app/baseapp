# @autodeck/design-tokens

AutoDeck's own independent design tokens (colors, spacing, type scale) — never AutoModz's design language. Consumed differently per platform: native components for the mobile apps, a web component set for customer-web/admin-web. Only the design language is shared; UI components are not shared pixel-for-pixel across native and web.

**Status**: Phase 0 complete. The token *shape* (colors, spacing, type scale) is defined and typed, using neutral placeholder values — AutoDeck's real brand palette has not been decided in any approved design document and is not assumed here.
